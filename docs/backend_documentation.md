# Tomato Leaf Health Detection - Backend Documentation

This document describes the structure, setup, and endpoints of the Tomato Leaf Health Detection API backend.

## Architecture & Technology Stack
- **Framework**: FastAPI (Python)
- **Database**: PostgreSQL (via Supabase) with SQLAlchemy Async (asyncpg)
- **Image Processing**: OpenCV, NumPy
- **AI/ML**: Custom Fuzzy Sugeno Orde 0 logic
- **Authentication**: JWT & bcrypt

## Project Structure
The backend is structured under the `backend/` directory with the following components:
- `app/main.py`: The entry point for the FastAPI application. Sets up CORS and routers.
- `app/api/v1/`: API endpoints categorized into `auth`, `prediction`, and `history`.
- `app/core/`: Configuration logic for environment variables (`config.py`) and database connections (`database.py`).
- `app/crud/`: Database interaction logic.
- `app/models/`: SQLAlchemy models mapping to PostgreSQL tables (`users` and `prediction_history`).
- `app/schemas/`: Pydantic models for request validation and response formatting.
- `app/services/`: Core business logic:
    - `image_processor.py`: Handles resizing, HSV masking, and feature extraction.
    - `fuzzy_engine.py`: Defines the triangular membership functions and 16 rules for prediction.
    - `supabase_service.py`: Helper for uploading prediction images to the Supabase Storage bucket.

## Setup Instructions

### 1. Requirements
Python 3.11+ is recommended. Navigate to the `backend/` directory and install the dependencies:
```bash
pip install -r requirements.txt
```

### 2. Environment Variables
Create a `.env` file in the `backend/` directory with the following variables:
```env
# Optional config
PROJECT_NAME="Tomato Leaf Health Detection API"

# Database connection (Use postgresql+asyncpg:// format)
DATABASE_URL="postgresql+asyncpg://postgres:your_password@db.yourproject.supabase.co:5432/postgres"

# Supabase Storage & API Keys
SUPABASE_URL="https://yourproject.supabase.co"
SUPABASE_KEY="your_anon_or_service_role_key"

# JWT Secret Key
SECRET_KEY="your_super_secret_key"
ALGORITHM="HS256"
```

### 3. Running the Server
Use Uvicorn to run the FastAPI app:
```bash
uvicorn app.main:app --reload --port 8000
```
Swagger UI will be available at: http://localhost:8000/docs

## API Endpoints

### Authentication
- `POST /api/v1/auth/register`: Register a new user with `email`, `full_name`, and `password`.
- `POST /api/v1/auth/login`: Login user and receive a JWT Bearer token.

### Prediction (v1)
- `POST /api/v1/predict`: Requires authentication. Expects a `multipart/form-data` payload containing an image file (field name: `image`). Returns the fuzzy score, severity, disease name, and the extracted features.


### Prediction (v2)
- `POST /api/v2/predict`: Requires authentication. Same as v1 but auto-saves result to database and returns full `PredictionRecordResponse` including `severity_score` field.

**v2 Response:**
```json
{
  "id": "uuid",
  "image_url": "https://storage.supabase.co/images/uuid.jpg",
  "severity_level": "Ringan",
  "plant_status": "Terinfeksi",
  "fuzzy_score": 71.25,
  "severity_score": 0.7125,
  "features": {
    "spot_area": 12.34,
    "color_change": 30.50,
    "yellow_ratio": 15.20,
    "brown_ratio": 2.80,
    "dark_ratio": 12.50,
    "spot_count": 5,
    "texture_var": 0.45
  },
  "created_at": "2026-06-01T10:30:00Z"
}
```


### History
- `GET /api/v1/history/`: Requires authentication. Fetches a paginated list of user's past predictions.
- `GET /api/v1/history/{prediction_id}`: Requires authentication. Fetches details for a specific prediction ID.

## Next Steps / Notes
- The database tables are automatically generated by SQLAlchemy when the application starts via the `lifespan` event (for development). In production, Alembic migrations are recommended.
- Make sure to create a bucket named `images` in Supabase Storage with appropriate RLS policies for the image upload to work correctly.
